# **App Name**: BrandVision

## Core Features:

- Dashboard Summary: Display a high-level overview of key brand performance indicators (KPIs).
- Brand Guidelines Viewer: Provide a clear, navigable presentation of brand guidelines.
- Asset Library: Organize approved brand assets for easy access and download.
- Content Calendar: Simplify content planning and scheduling with an intuitive calendar interface.

## Style Guidelines:

- Background color: True black (#000000) for an OLED dark mode experience.
- Primary color: Soft lavender (#E6E6FA) to align with iOS design aesthetics, offering a gentle and calming feel. It is bright and saturated enough to contrast against the dark background.
- Accent color: Light pastel violet (#D8BFD8), an analogous hue, providing subtle highlights without overpowering the interface.
- Body and headline font: 'Inter' (sans-serif) for a modern and clean aesthetic.
- Use minimalist vector icons with a thin stroke, filled with the accent color, consistent with iOS design language.
- Employ a grid-based layout with ample whitespace to ensure clarity and focus. Use rounded corners on containers and cards.
- Incorporate subtle, fluid transitions and animations for a smooth user experience, such as modal appearing by scaling up and fading in.
